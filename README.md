# CodeOn Practice Materials

Practice notebooks for the CodeOn curriculum.

## Layout

```
practice/    notebooks with exercises to fill in
solutions/   the same notebooks, completed and run
```

| Session | Topic | Practice | Solutions |
|---|---|---|---|
| 3 | Loops and Notebooks | [practice_03](practice/practice_03.ipynb) | [solutions_03](solutions/practice_solutions_03.ipynb) |

## Setup

```bash
git clone https://github.com/CodeOn-UM/codeon-practice-materials.git
cd codeon-practice-materials
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python -m pip install jupyter
```

Open the folder in VS Code, open a notebook from `practice/`, and pick the `.venv` kernel (top right).

Try each exercise before opening `solutions/`.
